## Acceptance criteria

- [ ] 结构以版本迁移为唯一执行来源，干净目标 MySQL 可初始化并启动应用；演示数据显式加载且与结构迁移分开，测试数据库与演示库隔离。
- [ ] 提供四类模拟演示账号及可复现数据加载方法，普通启动不重置数据；不包含真实学生资料、真实凭据或本机敏感配置。
- [ ] 交付实际数据库结构/ER 图、接口说明、本地环境与启动停止/故障排查、测试记录、四角色演示步骤；文档随真实实现核验，不另存易分歧建表来源。
- [ ] 按 Spec 全部 AC-01–AC-24 作跨模块回归，包含权限/附件、床位与评分并发、事务失败、ISO 边界、草稿、停检补录、统计、更正整改。
- [ ] 真实浏览器在 1920×1080 和 1366×768 完成四角色主要路径；模拟成功、原型测试或替代数据库结果均不能充当正式验收。
- [ ] 从隔离干净环境执行前端 Node/npm、后端 Java/Maven、Compose MySQL 的实际复现；记录实际端口、版本、命令和停止方式，脚本仅管理本项目资源。
- [ ] 汇总 17 的真实性能结果与安全验证记录；已知缺陷、未验证环境/平台及未执行项单列，全部核心验收通过才报告开发完成。
