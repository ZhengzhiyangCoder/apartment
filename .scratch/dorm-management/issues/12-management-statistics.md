## What to build

系统管理员与宿舍管理员按周/月、全校/楼栋/寝室查询同源成绩，比较楼栋均分与同方案维度，明确样本和检查进度。

## Acceptance criteria

- [x] 管理角色能查询全校、楼栋和寝室范围的成绩/趋势/排行，复用 11 的周期和有效样本规则；学生与维修人员不能借管理接口扩大范围。
- [x] 楼栋平均成绩先算各寝室有效周期成绩，再对有成绩寝室等权平均；A 两次 100、100，B 一次 0，月楼栋均分为 50.00。
- [x] 楼栋均分同时展示参评寝室数与检查进度；不改变单间成绩、排名或整改触发，不把缺检算零。
- [x] 维度只在相同方案版本及相同口径内比较；跨方案分别展示版本、维度与样本，不把同名不同定义维度混算。
- [x] 停检不参加完成率考核、排行和有效趋势，缺检保持空缺；无有效样本有明确空状态，不产生除零或误导性零分。
- [x] 实际图表、列表与详情口径一致，筛选分页可操作；两种桌面尺寸下可读且关键按钮不被遮挡。
- [x] 真实 API 用固定样本验证楼栋 50.00、跨版本维度、有效参评次数；浏览器验证管理角色筛选及图表与明细对应。
