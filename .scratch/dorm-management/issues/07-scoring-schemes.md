## What to build

系统管理员在页面维护评分维度、权重和阈值，启用一个供新批次使用的版本，并查看历史标准。

## Acceptance criteria

- [x] 可维护维度、名称、权重和整改阈值；权重最多两位小数，启用时合计严格为 100%；阈值默认 60。
- [x] 同一时间只有一个供新批次采用的启用版本；并发启用不产生多个有效版本，失败不留下部分启用状态。
- [x] 已被批次引用的维度、权重和阈值不能原地修改，调整产生新版本；历史版本可查询且不被覆盖。
- [x] 系统管理员才能维护；宿舍管理员可查看工作所用标准，学生查看成绩对应标准的入口由 11 完成；维修人员不能访问卫生管理数据。
- [x] 方案操作与审计一致保存；非法权重与权限错误在 API 和页面均有明确反馈。
- [x] 真实 MySQL 与浏览器验证版本创建、启用和历史查看；当前阶段无引用时不得用伪造引用宣称绑定冻结已验收，08 负责真实批次绑定回归。
