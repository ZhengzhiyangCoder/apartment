## What to build

系统管理员在页面维护评分维度、权重和阈值，启用一个供新批次使用的版本，并查看历史标准。

## Acceptance criteria

- [ ] 可维护维度、名称、权重和整改阈值；权重最多两位小数，启用时合计严格为 100%；阈值默认 60。
- [ ] 同一时间只有一个供新批次采用的启用版本；并发启用不产生多个有效版本，失败不留下部分启用状态。
- [ ] 已被批次引用的维度、权重和阈值不能原地修改，调整产生新版本；历史版本可查询且不被覆盖。
- [ ] 系统管理员才能维护；宿舍管理员可查看工作所用标准，学生查看成绩对应标准的入口由 11 完成；维修人员不能访问卫生管理数据。
- [ ] 方案操作与审计一致保存；非法权重与权限错误在 API 和页面均有明确反馈。
- [ ] 真实 MySQL 与浏览器验证版本创建、启用和历史查看；当前阶段无引用时不得用伪造引用宣称绑定冻结已验收，08 负责真实批次绑定回归。

## 验证与可演示结果

用 40%、30%、30% 创建并启用方案，再试不等于 100% 及超小数位权重；真实绑定后的不可变性在 08/10 通过完整评分链路验证。

每个功能切片同步交付必要迁移、服务端授权及事务校验、实际页面、最小模拟数据、公开 API / 真实 MySQL 验证与必要浏览器证据。相关数据库、接口、运行或测试说明随切片更新；通用完成条件见总览。
