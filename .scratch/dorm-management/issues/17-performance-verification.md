## What to build

以批准的数据规模在本机实际测量普通列表与统计看板，定位不达标查询并在不改变业务口径和权限的前提下优化。

## Acceptance criteria

- [ ] 生成明确标注的模拟数据：约 5,000 名学生、1,000 间寝室、全年评分，覆盖已有业务关键状态；同时观察 10/100/1000 间寝室场景。
- [ ] 测试数据与日常演示数据库隔离；加载入口明确目标数据库，不接触不明用途的既有数据。
- [ ] 测量前固定并记录被测接口、硬件/软件、数据分布、并发数、预热、样本量和计时边界，再执行测量；具体并发与样本值是测试设计细节，不把未批准值写成既定 Spec。
- [ ] 普通列表查询 P95 < 2 秒、统计看板查询 P95 < 3 秒；两类分别给出真实结果，不能用合并平均数掩盖慢接口或把目标写成成绩。
- [ ] 分页与上限、查询参数/排序白名单及必要索引有效；性能调整后用 11/12/14 的固定统计样本与权限请求回归，浏览器筛选/加载行为仍正确。
- [ ] 不达标时定位、优化并复测；报告保存测量口径、实际结果及未测项，不达标或未执行不得标为完成。
