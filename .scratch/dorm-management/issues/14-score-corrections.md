## What to build

系统管理员有理由地更正同一份正式成绩，所有明细、统计与排行反映当前值，同时保留审计和关联整改历史。

## Acceptance criteria

- [ ] 仅系统管理员可更正，必须填写原因；沿用原批次方案重校维度与分值并重新计算，不能改变寝室/批次或新增第二份同周成绩。
- [ ] 保留同一评分身份、完整前后值、操作者、时间和原因；关闭批次允许有审计更正，停检成绩即使更正仍不参加有效统计。
- [ ] 并发更正检测版本冲突，后一操作者不能无提示覆盖；失败保留可恢复表单并展示冲突原因。
- [ ] 更正后学生/管理端明细、周月成绩、排行、楼栋均分和维度图表一致反映当前有效值，原结果仍可追溯。
- [ ] 更正导致低于固定阈值时生成或复用未关闭整改；原触发成绩更正达标时保留事件和跟进，显示触发成绩已更正，由管理角色核实关闭。
- [ ] 评分、更正明细、整改关联和关键日志在同一业务事务内；任一步失败时不能出现分数已改而整改/日志仍旧的部分状态。
- [ ] 实际 API 和浏览器验证权限、并发、关闭批次更正、由高变低/低变高及跟进保留；再次复核 11/12 的统计期望值。
