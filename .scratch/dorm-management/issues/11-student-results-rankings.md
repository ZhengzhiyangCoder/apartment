## What to build

学生从当前住宿进入成绩明细、历史趋势和当前楼栋周/月排行，所有展示来自同一套有效成绩口径和服务端数据范围。

## Acceptance criteria

- [ ] 学生可查当前寝室成绩与对应历史标准、趋势，以及当前楼栋排行；篡改寝室/楼栋参数不能访问旧寝室或其他楼栋。
- [ ] 未入住显示明确提示，不能访问寝室成绩/楼栋排行；调寝后可看新寝室历史并失去旧寝室成绩权限，本人旧工单仍按 05 规则可见。
- [ ] 周成绩用该批次当前有效正式值；月成绩按批次周一归月取有效周成绩算术平均，最后保留两位，80 与 90 得 85.00。
- [ ] 跨年使用 ISO 年周；跨月周全部寝室统一按周一归月，补录不按实际提交日期改归属；缺检、停检和草稿不补零、不计平均。
- [ ] 至少一次有效记录才参与排名；按最终两位小数实行竞赛排名，90、90、80 得 1、1、3，同分以房号稳定排序；无有效成绩显示未检查/数据不足。
- [ ] 榜单只展示寝室编号、周期成绩、有效参评次数和名次，不披露学生姓名；趋势显示空缺，表格、图表、明细显示周期与样本且口径一致。
- [ ] 公开 API 以固定期望值验证统计、权限及停检/恢复；真实浏览器演示学生成绩、趋势、排行、调寝前后权限与无数据状态。
