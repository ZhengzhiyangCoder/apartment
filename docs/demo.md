# 任务 01 演示

先按 [本地运行](local-run.md)启动 MySQL 和后端，使版本迁移完成，然后显式执行：

```bash
./scripts/seed-demo.sh
```

以下全部为模拟账号，初始演示密码均为 `DemoPass2026!`，用于本机隔离演示，不能当作真实部署凭据。

| 账号 | 角色 |
|---|---|
| system_admin | 系统管理员 |
| dorm_manager | 宿舍管理员（学生会宿管部成员） |
| student | 学生 |
| maintainer | 维修人员 |

重复加载只补缺少的模拟账号，保留已有密码和数据；不会在每次启动时重置。改密后使用新密码登录。

## 本切片演示路径

1. 打开 `http://127.0.0.1:5174`，输入一个模拟账号登录。
2. 查看对应角色工作台入口，刷新页面确认会话仍可用。
3. 进入个人资料，确认账号、姓名与角色来自当前登录账号。
4. 修改密码，错误原密码或非法新密码有明确提示；成功后重新登录。
5. 退出，刷新或返回受保护地址应要求重新登录。

住宿、报修、卫生等后续业务不提供假数据或模拟按钮。完整四角色业务演示由任务 18 汇总。
