# 栖居 · 宿舍管理系统 HTML 交互原型

版本 V0.1，2026-11-11。入口：[index.html](index.html)。

当前状态：用户比较两版后明确选择本版（方案 A，灰蓝新拟态），后续界面以此为基准。此选择不代表 Spec 已全部批准或正式系统实现已开始。

用浏览器打开 `index.html` 即可。样式、SVG 图标、图表与交互均在单个 HTML 内，无需 npm、后端、数据库或外部 CDN。未安装字体时使用附件允许的系统字体回退。

用户已在 Spec 审核中确认保留原型名称，界面展示名为“栖居 · 高校宿舍管理系统”。所有人物、寝室、工单与成绩都是演示数据。刷新页面或点击左下角“重置演示”恢复初始数据。

## 视觉规格

| 项目 | 原型选择 |
|---|---|
| 基底 | 页面、面板、按钮、输入框统一 `#e0e5ec` |
| 光源 | 左上白色高光，右下 `#b8bcc2` 阴影 |
| 层次 | 凸起卡片、凹陷输入框及选中态，常态无实线边框 |
| 强调 | `#6d5dfc` 操作和选中状态；薄荷色成功、珊瑚色待关注状态 |
| 文字 | `#3d4451` 正文，Inter／系统字体回退，常规字重 400–600 |
| 圆角 | 面板 24px、按钮和输入框 16px、状态标签胶囊形 |
| 布局 | 固定侧栏 + 顶栏 + 最大 1080px 内容区；工作区内卡片间距 32px |
| 密度处理 | 将附件展示型页面的 96px 区段节奏调整为工作台的 32px 卡片分组间距，保留 8px 间距体系与阴影所需留白，便于桌面操作 |
| 图片 | 不使用摄影或装饰性大图；报修上传照片仅用于问题信息 |
| 交互 | 原生键盘控件、可见焦点、弹窗 Esc 关闭、减少动画媒体设置、必填/数值校验、禁用与空状态 |

## 界面与操作覆盖

| 工作区 | 主要界面 | 可演示操作 |
|---|---|---|
| 工作台 | 宿管/管理员总览、学生主页、维修工作台 | 待办跳转、四角色切换、个人资料、登录预览与密码表单 |
| 住宿管理 | 楼栋寝室卡片、床位详情、学生名册、账号、操作记录 | 寝室搜索、新增寝室、办理入住/调寝/退宿、账号创建/设置 |
| 卫生检查 | 周检名单、连续评分、周/月榜单、寝室趋势、维度对比、整改、评分标准 | 筛选、加权预览、草稿恢复、保存并下一间、管理员更正、整改跟进/关闭、批次状态、新方案版本 |
| 报修工单 | 状态筛选、提交表单、图片预览、详情与处理时间线 | 学生提交/取消、管理员派单/重分配、维修人员开始/完成、学生查看结果 |

角色限制体现在菜单和可见操作中：系统管理员不录入普通检查分数；宿管跨楼栋录分；学生仅见当前楼栋排行和本人报修；维修人员仅见本人任务。这里只模拟界面行为，不能代替正式服务端权限校验。

## 推荐审阅路径

1. 默认宿舍管理员 → 继续本周检查 → 输入 80、90、70 → 总分 80.00 → 暂存草稿或保存并下一间。
2. 切换学生 → 提交报修 → 切换宿舍管理员派给周师傅 → 切换维修人员开始并完成 → 切回学生查看时间线。
3. 切换系统管理员 → 住宿管理 → 学生与入住 → 将许知远调到空床 → 切回学生检查当前寝室和排行范围。
4. 系统管理员 → 周检批次 → B203 成绩明细 → 更正为合格 → 整改跟进保留“触发成绩已更正”提示 → 核实关闭。
5. 系统管理员 → 评分标准 → 创建新版本。权重合计不等于 100% 时阻止保存；新版本不改变当前批次 V1。

## 原型边界

- 页面内操作只保存在当前页面内存中；刷新即重置。草稿不是服务端持久化，账号密码不会保存。
- 真实认证、数据权限、并发控制、事务、数据库、上传安全和性能验收均未实施，不能以原型演示替代 Spec 的正式验收。
- 本版以三个楼栋、四人间、当前 W46 批次和三个评分维度为演示范围。完整楼栋维护、任意床位配置、学生资料编辑、历史批次重开、应检名单调整、维度增删、完整审计检索暂未绘制专门编辑界面；Spec 中相关功能仍保留。
- 图片选择具备数量、大小、格式提示和浏览器解码预览；服务端真实文件内容与授权读取未实现。
- 仅完成桌面目标尺寸的实际检查，未执行 Safari/Firefox 或移动设备验收。
- 当前只供界面审核，尚未拆开发票、搭建正式前后端或启动数据库。后续根据用户反馈修订设计。
